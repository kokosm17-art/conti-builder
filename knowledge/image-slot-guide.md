# 상세페이지 이미지 슬롯 배치 가이드

실제 와디즈 상세페이지 5개 사례(한일 이동식 에어컨, 타밈 에어 젤리브라, 올리젯 이태리 데님, 프휘 선데이션, Hey2 AI 안경)를 분석한 이미지 슬롯 배치 패턴이다. 콘티 작성 시 아래 패턴을 참고하여 텍스트 문단 사이 (이미지 슬롯)을 배치하라.

---

## 1. 이미지 슬롯 배치 원칙

- 텍스트 문단이 4~5줄 이상 이어지면 반드시 이미지 슬롯을 삽입한다
- 새로운 USP나 주제가 시작되기 전 이미지 슬롯으로 호흡을 끊는다
- 수치/스펙 강조 문구 뒤에는 반드시 이미지 슬롯으로 시각적 근거를 제시한다
- 감성적 카피 다음에는 라이프스타일 이미지 슬롯을 배치한다
- 기능 설명 나열 후에는 해당 기능의 클로즈업 컷을 배치한다

---

## 2. 섹션별 이미지 슬롯 패턴

### 도입부 이미지 슬롯
후킹 카피 직후, 가장 강렬한 첫인상을 주는 이미지가 온다.

(제품 전면 단독 컷 — 흰 배경 또는 브랜드 컬러 배경, 제품이 주인공이 되도록)
(메이커 제공 대표 이미지 — 브랜드 감성이 가장 잘 드러나는 컷)
(착용/사용 중인 모델 전신 컷 — 제품의 존재감을 처음 각인시키는 컷)

### 본론부 이미지 슬롯 — USP별 패턴
각 USP 설명 후 해당 특장점을 시각적으로 증명하는 이미지가 온다.

**기능/기술 USP일 때:**
(핵심 기능 클로즈업 컷 — 버튼·소재·부품 등 기능이 보이도록)
(기능 설명 인포그래픽 또는 도식화 이미지 — 구조/작동 원리를 한눈에)
(사용 전·후 비교 컷 — 동일 앵글, 동일 배경으로 차이를 명확하게)

**소재/품질 USP일 때:**
(원단·소재 텍스처 클로즈업 — 손으로 만지는 느낌이 전달되도록)
(스티칭·마감 디테일 컷 — 품질 감을 증명하는 디테일 부위)
(세탁/내구성 테스트 결과 컷 — 변형 없음을 증명하는 비교 이미지)

**착용/사용감 USP일 때:**
(모델 착용 정면·측면·후면 컷 — 핏과 실루엣이 잘 보이도록)
(다양한 체형·피부톤 모델 착용 컷 — 누구에게나 어울림을 증명)
(착용 클로즈업 — 피부 밀착감, 착용 편의성이 느껴지는 부위)

**라이프스타일 USP일 때:**
(실제 사용 환경 라이프스타일 컷 — 자연광, 일상적 배경)
(모델 표정·감정 클로즈업 — 편안함·만족감·자신감 표현)
(야외/실내 다양한 환경 착용/사용 컷)

### 결론부 이미지 슬롯
구매 전환을 돕는 정보성 이미지들이 온다.

(색상·옵션 라인업 플랫레이 — 모든 컬러/옵션을 한눈에)
(사이즈 차트 또는 스펙 도표 이미지)
(리워드 구성 패키지 전체 컷 — 박스 오픈 또는 구성품 나열)
(메이커/브랜드 소개 이미지 — 공장·작업실·팀 사진)
(실제 고객 리뷰 이미지 또는 후기 모음 컷)

## 3. 카테고리별 이미지 슬롯 특성

### 가전/테크 제품 (한일 이동식 에어컨, Hey2 AI 안경 참고)
- 제품 단독 컷 비중이 높다 (흰 배경 또는 어두운 하이라이트 배경)
- 수치 강조 그래픽 (BTU, 무게, 전력 등)을 이미지로 삽입
- 앱 연동·디지털 기능은 스크린샷 + 제품 합성 이미지
- 부품 분해 도식 또는 내부 구조 인포그래픽
- 사이즈 비교 도식 (사람 실루엣 옆에 제품 크기 표시)

예시 슬롯 문구:
(제품 전면 단독 컷 — 흰 배경, 슬림한 디자인이 강조되도록)
(8,000BTU 수치 강조 그래픽 — 냉방 면적과 함께 한눈에)
(배수 호스 연결 클로즈업 — 셀프 설치 간편함 증명)
(앱 연동 화면 + 제품 합성 이미지 — 스마트 기능 직관적으로)
(1130W 전력 수치 강조 — 절전 효과 비교 그래픽)
(실내 거실 설치 라이프스타일 컷 — 자연스러운 인테리어 연출)

### 패션/의류 (올리젯 이태리 데님 참고)
- 전신 착용 컷이 핵심 (다양한 각도: 정면·측면·후면)
- 원단 텍스처 클로즈업은 소재 USP 직후 배치
- 핏 비교는 다양한 체형 모델로 구성
- 디테일 컷 (주머니·스티칭·라벨)은 품질 USP 직후
- 색상 라인업은 결론부에 플랫레이로 정리

예시 슬롯 문구:
(이태리 원단 텍스처 클로즈업 — 고급스러운 소재감이 전달되도록)
(모델 착용 정면 전신 컷 — 깔끔한 실루엣과 핏이 보이도록)
(주머니·스티칭 디테일 클로즈업 — 마감 품질 증명)
(다양한 체형 모델 착용 비교 — 핏의 범용성 증명)
(색상 라인업 플랫레이 — 미드블루·다크인디고 등 전 컬러)
(세탁 전·후 비교 컷 — 동일 조건에서 변형 없음 증명)

### 이너웨어/언더웨어 (타밈 에어 젤리브라 참고)
- 착용 전면·측면·후면 컷 순서로 배치
- 소재 레이어 구조 도식은 기능 설명 직후
- 편안함을 표현하는 모델 표정·감성 컷
- 기존 제품과의 착용 비교 컷 (불편함 vs 편안함 대비)
- 색상칩 + 색상명은 결론부에

예시 슬롯 문구:
(젤리브라 착용 정면 컷 — 자연스러운 라인이 보이도록)
(소재 레이어 구조 도식 — 에어메쉬·젤리패드 구조 한눈에)
(착용 모델 편안한 표정 클로즈업 — 무압박 착용감 감성 표현)
(기존 브라 vs 젤리브라 착용 비교 — 동일 모델, 동일 앵글)
(에어메쉬 소재 클로즈업 — 통기성 느껴지는 구조)
(색상 라인업 — 블랙·베이지·그레이 전 컬러 플랫레이)

### 뷰티/코스메틱 (프휘 선데이션 참고)
- 제품 용기 단독 컷 (감성적 배경)
- 손등·팔 발림성 텍스처 컷은 소재 USP 직후
- 피부 밀착 클로즈업은 효과 USP 직후
- 다양한 피부톤 모델 적용 비교 컷
- Before/After 얼굴 컷은 효과 증명 직후
- 성분 강조 인포그래픽 (원료 이미지 + 성분명)

예시 슬롯 문구:
(선데이션 제품 단독 컷 — 따뜻한 오렌지 배경, 용기 디테일 강조)
(손등 발림성 텍스처 컷 — 가볍게 퍼지는 질감 표현)
(피부 밀착 클로즈업 — 모공 커버·자연스러운 마감 증명)
(다양한 피부톤 모델 적용 컷 — 21호·23호·25호 비교)
(성분 원료 이미지 + 성분명 인포그래픽 — 히알루론산·콜라겐 등)
(Before·After 얼굴 비교 컷 — 동일 조명, 동일 각도)
