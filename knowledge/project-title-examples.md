# 프로젝트 제목 작성 가이드 (실제 와디즈 캠페인 타이틀 55개 분석)

실제 와디즈에서 성과를 낸 캠페인 타이틀 55개를 분석해 공통 구조와 11가지 유형으로 정리했다.
프로젝트 제목 후보 3개를 작성할 때 아래 구조·유형을 "사고의 틀"로 참고하되, 예시 문구를 그대로
베끼지 말고 사용자의 실제 제품에 맞게 새로 창작하라.

---

## 0. 공통 구조 원칙

거의 모든 사례가 아래 2단 구조를 따른다.

**[태그/후킹 요소] + 구분자(ㅣ 또는 [ ] 또는 < >) + 핵심 카피 문장(+ 제품명)**

- 태그 자리: 실적 수치, 희소성 정보, 브랜드명, 한정 조건 등 "신뢰·긴급성"을 압축한 한 조각
- 카피 문장 자리: 궁금증, 반전, 감탄, 공감 등 감정을 건드리는 표현 + 필요 시 제품명
- 구분자 없이 한 문장으로만 구성되는 경우도 있다(예: "마스카라 아니에요. 속눈썹 영양제에요.") — 태그가 꼭 필요한 것은 아니다.
- 전체 길이는 공백 포함 40자를 넘지 않는다. 예외 없음.
- 전체 길이는 공백 포함 최소 36자(40자의 90%) 이상이어야 한다. 여백을 남기지 말고 36~40자 범위를 채운다.

## 2. 제목 후보 3개를 만들 때

1. 위 11개 유형 중 사용자의 제품·USP·톤앤매너에 가장 잘 맞는 유형을 서로 다른 3개 골라라.
   (예: 궁금증·반전 유발형 1개 + 수치·데이터 신뢰형 1개 + 비유·은유형 1개 — 유형을 겹치지 말 것)
2. 예시 문구의 단어·구절을 그대로 가져오지 말고, 위 "공통 구조 원칙"(태그+구분자+카피)만 참고해
   사용자의 실제 제품 정보로 새로 창작하라.
3. 공백 포함 36~40자 범위(최소 90% 채움)와 마크다운 금지 규칙은 유형과 무관하게 항상 지켜야 한다.
