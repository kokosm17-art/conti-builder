실제 뷰티/스킨케어 상세페이지 3건(마스크시트, 앰플 2종)을 실측 분석한 카피 패턴. 아래는 관찰된 카피 유형과, 다른 뷰티 제품 콘티 작성 시 적용 방향이다.

카피 패턴 (관찰 사례)	적용 방향

"잡티 다 낡아드릴게요" / "ULTRA 극단적으로 옅어진다는"
문제 부위를 구체적으로 짚은 뒤, 강한 부사(완전히/극단적으로/확)로 개선을 과감하게 약속
→ 사용자가 제시한 피부 고민(예: 색소침착, 붉은기, 모공)을 구체적으로 짚고, 그 개선을 과감한 부사로 강조하는 카피에 활용

"72시간 지속력" / "6,317명이 선택"
숫자(지속시간, 참여·구매 인원)를 헤드라인급으로 크게 노출
→ 사용자가 임상 결과·판매량 등 실제 수치를 제공한 경우, 그 수치를 문장 전체의 중심에 두는 헤드라인으로 활용 (수치가 없으면 지어내지 말 것)

"그 성분" / "단 한 방울의 힘"
핵심 성분 하나를 지칭사("그 성분", "이 한 방울")로 신비화해 임팩트 있게 소개
→ 사용자가 제공한 핵심 성분·기술이 하나로 특정될 때, 정보 나열 대신 "그 성분", "이 한 방울" 식으로 궁금증을 유발한 뒤 이어서 설명하는 구조에 활용

"FDA가 까다로운 기준으로 승인한 원료"
공인 기관·인증명을 짧고 강하게 인용해 신뢰도 부여
→ 사용자가 인증·수상·기관 승인 정보를 제공한 경우, 설명을 늘어놓지 말고 인증명을 그대로 임팩트 있게 인용

"고운 얼굴에, 잔한 남기세요" (Before) → "잡티만 잡아준다면" (After 전환)
사용 전 상태와 사용 후 상태를 대구(對句) 형태로 짧게 대비시키는 문장 구조
→ 비포/애프터 이미지 슬롯과 짝을 이루는 카피로, "~하던 얼굴이" / "~해집니다"처럼 전후를 짧게 대비하는 문장 구조에 활용

⚠ 주의: 위 사례의 구체적 수치·성분명·인증명은 예시일 뿐이며, 실제 콘티에는 사용자가 입력한 정보만 사용한다. 사용자가 제공하지 않은 수치·성분·인증을 위 사례에서 그대로 가져와 쓰지 않는다.
